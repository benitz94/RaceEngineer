# Contributing to RaceEngineer

Thank you for your interest in RaceEngineer.

Read `README.md`, `ARCHITECTURE.md`, `ROADMAP.md`, and `AGENTS.md`
before opening a pull request.

The official repository language is English. Discussion with the
maintainer may be in Italian. Files committed to the repository must be
in English.

## Contributor License Agreement

External contributions are accepted only under a Contributor License
Agreement.

- If You own the Contribution: accept `CLA.md` version 1.0.
- If an organization owns the Contribution: that organization must
  accept `CLA-ENTITY.md` before the contribution is merged.
  The Entity CLA is not required for ordinary individual contributors.

### How to accept CLA.md

In the pull request description or in a pull request comment, include
this exact statement:

    I have read CLA.md (v1.0) and I accept it for this contribution
    and my subsequent contributions.

That statement accepts CLA.md version 1.0 for the Contribution in that
pull request and for your subsequent Contributions, until you notify
the maintainer in writing that future submissions are excluded.
Licenses already granted cannot be revoked.

Opening a pull request without that statement does not accept the CLA.

The record of acceptance is the GitHub pull request together with the
versioned `CLA.md` in this repository. This project does not keep a
separate public file of contributor personal data.

### What the CLA does

You keep copyright in your Contribution.

You grant the maintainer rights needed to use, modify, distribute,
sublicense, and relicense the Contribution in the official Project,
including:

- public distribution under GPL-3.0-only; and
- parallel alternative or proprietary licensing of the official
  Project.

The public Project is intended to remain available under GPL-3.0-only.
The CLA is not a plan to withdraw that public offering.

## Pull requests

Keep each pull request narrow.

Do not invent requirements.

Do not mix this repository with unrelated private projects.

Keep simulator-specific logic out of the core.

Do not include unrelated formatting or documentation rewrites.
